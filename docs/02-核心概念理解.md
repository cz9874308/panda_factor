## 2.1 什么是因子？

### 生活化类比：选水果

想象你去水果店买苹果，你会怎么挑选？

- 看颜色（越红越好）
- 看大小（越大越好）
- 闻香味（越香越好）
- 敲一敲（声音清脆说明新鲜）

这些"挑选标准"就是你选苹果的**因子**。

在股票投资中也是一样：

| 生活场景 | 股票投资 |
|----------|----------|
| 苹果越红越好 | 市盈率越低越好（价值因子） |
| 苹果越大越好 | 涨幅越大越好（动量因子） |
| 苹果越香越好 | ROE 越高越好（质量因子） |

### 量化定义

> **因子（Factor）** 是用来衡量股票某种特征的量化指标，通常用于预测股票未来的收益。

简单来说：**因子 = 选股的量化标准**

### 因子的本质

每个因子本质上是在回答一个问题：

```
因子值高的股票，未来收益是否也更高（或更低）？
```

如果答案是"是"，这个因子就有**预测能力**，就是一个有效的因子。

### 因子的类型

| 类型 | 含义 | 例子 |
|------|------|------|
| **动量因子** | 强者恒强 | 过去 20 日涨幅 |
| **价值因子** | 低估会涨 | 市盈率、市净率 |
| **质量因子** | 好公司会涨 | ROE、毛利率 |
| **波动因子** | 低波动更稳 | 收益率标准差 |
| **量价因子** | 量价关系 | 换手率、成交额 |
| **技术因子** | 技术分析 | MACD、RSI |

## 2.2 因子分析的目标

### 为什么要分析因子？

你有一个选股想法，比如"买入市盈率最低的股票"。但这个想法真的有效吗？

因子分析的目标就是：**用历史数据验证你的想法是否有效**。

### 好因子的标准

一个"好"因子应该具备：

| 标准 | 说明 | 指标 |
|------|------|------|
| **预测能力** | 能预测未来收益 | IC > 0.03 或 < -0.03 |
| **稳定性** | 预测能力稳定 | IR > 0.5 |
| **单调性** | 分组收益有序 | 第1组 > 第2组 > ... > 第N组 |
| **区分度** | 能区分好坏股票 | 多空组合收益显著 |

---

## 2.3 核心指标解读

### 2.3.1 IC（信息系数）

#### 通俗解释

> **IC** 衡量的是：因子值和未来收益的相关性有多强。

打个比方：
- 如果"身高"和"篮球水平"相关性很高，那"身高"就是预测篮球水平的好因子
- 如果"因子值"和"未来收益"相关性很高，那这个因子就是预测股票收益的好因子

#### 计算方式（了解即可）

```
IC = 相关系数(因子值排名, 未来收益排名)
```

#### IC 值的解读

| IC 值 | 解读 |
|-------|------|
| IC > 0.05 | 强正相关，因子值越高收益越高 |
| 0.03 < IC < 0.05 | 中等正相关，有一定预测能力 |
| -0.03 < IC < 0.03 | 基本无相关性，因子无效 |
| -0.05 < IC < -0.03 | 中等负相关，因子值越高收益越低 |
| IC < -0.05 | 强负相关，可以反向使用 |

#### 重要提示

IC 是**单期**的指标，每天/每周/每月都会有一个 IC 值。我们通常关注：
- **IC 均值**：所有期 IC 的平均值
- **IC 标准差**：IC 的波动程度

### 2.3.2 IR（信息比率）

#### 通俗解释

> **IR** 衡量的是：因子预测能力的"稳定性"。

IC 高但不稳定，和 IC 中等但稳定，哪个更好？

答案是后者。因为不稳定的因子难以使用。

IR 就是用来衡量这种"稳定性"的指标。

#### 计算方式

```
IR = IC均值 / IC标准差
```

#### IR 值的解读

| IR 值 | 解读 |
|-------|------|
| IR > 1.0 | 优秀，因子预测能力强且稳定 |
| 0.5 < IR < 1.0 | 良好，可以使用 |
| 0 < IR < 0.5 | 一般，谨慎使用 |
| IR < 0 | 较差，因子可能无效 |

#### IC 和 IR 的关系

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   IC 均值高 + IR 高  →  最好的因子！预测准且稳定    │
│   IC 均值高 + IR 低  →  时灵时不灵，难以使用        │
│   IC 均值低 + IR 高  →  稳定但没用                  │
│   IC 均值低 + IR 低  →  完全无效                    │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 2.3.3 分组收益

#### 通俗解释

分组收益是验证因子有效性最直观的方法：

1. 每天按因子值将所有股票排序
2. 分成 N 组（通常 5 或 10 组）
3. 计算每组的平均收益
4. 观察不同组的收益差异

#### 分组原理图解

假设有 100 只股票，分成 5 组：

```
因子值从小到大排序
┌─────────────────────────────────────────────────────────────┐
│  股票1  股票2  ...  股票20 │ 股票21 ... │ ... │ ... │ 股票81 ... 股票100 │
│         第1组              │    第2组    │ 第3组│ 第4组│       第5组        │
│      (因子值最小)          │             │      │      │    (因子值最大)    │
└─────────────────────────────────────────────────────────────┘
```

#### 怎么看分组结果？

理想情况（正向因子）：

```
收益率
  ↑
  │                                        ████
  │                              ████      ████
  │                    ████      ████      ████
  │          ████      ████      ████      ████
  │ ████     ████      ████      ████      ████
  └────────────────────────────────────────────→ 分组
    第1组    第2组     第3组     第4组     第5组
   (因子值小)                              (因子值大)
```

如果分组收益呈现**单调递增**（或递减），说明因子有效。

#### 常见的分组模式

| 模式 | 图形 | 解读 |
|------|------|------|
| 单调递增 | 第1组<第2组<...<第N组 | 正向因子，因子值越大越好 |
| 单调递减 | 第1组>第2组>...>第N组 | 负向因子，因子值越小越好 |
| U 型 | 两端高，中间低 | 非线性关系 |
| 倒 U 型 | 两端低，中间高 | 非线性关系 |
| 无规律 | 随机分布 | 因子无效 |

### 关键参数说明

| 参数 | 说明 | 常用设置 |
|------|------|----------|
| 回测区间 | 分析的时间范围 | 1年/3年/5年 |

| 因子方向 | 因子值大是好还是坏 | 正向/负向 |

## 2.5 实际案例

### 案例：动量因子分析

假设我们创建一个简单的动量因子：**过去 20 日收益率**

#### 因子定义

```python
因子值 = (今日收盘价 / 20日前收盘价) - 1
```

#### 预期逻辑

- 动量效应：涨得好的股票继续涨
- 因子值越高（过去涨得越多）→ 未来收益越高

#### 分析结果示例

![动量因子分析结果](./images/02-momentum-analysis.png)

**IC 指标**：
- IC 均值：0.035
- IC 标准差：0.12
- IR：0.29

**解读**：
- IC 均值为正，说明因子有一定的预测能力
- IR 较低，说明预测能力不太稳定
- 结论：这是一个弱有效因子

## 💡 本课小结

### 核心要点

1. **因子 = 选股的量化标准**，用来预测股票未来收益

2. **IC 衡量预测能力**
   - IC > 0.03：正向预测能力
   - IC < -0.03：负向预测能力

3. **IR 衡量稳定性**
   - IR = IC均值 / IC标准差
   - IR > 0.5 是良好的因子

4. **分组收益**验证因子有效性
   - 单调递增/递减 = 因子有效
   - 无规律 = 因子无效

5. **好因子的标准**
   - 预测能力强（IC 高）
   - 预测稳定（IR 高）
   - 分组单调
