## 1. 环境安装问题

### Q1.1: Python 安装后命令行找不到 `python` 命令

**问题描述**：
```
'python' 不是内部或外部命令，也不是可运行的程序或批处理文件。
```

**解决方案**：

**Windows**：
1. 重新运行 Python 安装程序
2. 勾选 "Add Python to PATH"
3. 重启命令行窗口

或手动添加 PATH：
```
1. 右键"此电脑" → 属性 → 高级系统设置
2. 环境变量 → Path → 编辑
3. 添加 Python 安装目录（如 C:\Python310）
4. 添加 Scripts 目录（如 C:\Python310\Scripts）
```

**macOS/Linux**：
```bash
# 检查 python3 是否可用
python3 --version

# 创建别名（可选）
echo "alias python=python3" >> ~/.bashrc
source ~/.bashrc
```

### Q1.2: pip 安装依赖时超时或失败

**问题描述**：

ERROR: Could not find a version that satisfies the requirement xxx

**解决方案**：

| 阿里云 | https://mirrors.aliyun.com/pypi/simple |
| 中科大 | https://pypi.mirrors.ustc.edu.cn/simple |

### Q1.3: MongoDB 连接失败

**问题描述**：
```
pymongo.errors.ServerSelectionTimeoutError: localhost:27017
```

**排查步骤**：

1. **检查 MongoDB 服务是否启动**

Windows：
```powershell
# 查看服务状态
Get-Service MongoDB

# 启动服务
Start-Service MongoDB
```

macOS：
```bash
brew services list
brew services start mongodb-community
```

Linux：
```bash
sudo systemctl status mongod
sudo systemctl start mongod
```

2. **检查连接参数**

确认 `config.yaml` 中的配置：
```yaml
MONGO_URI: "127.0.0.1:27017"
MONGO_USER: "panda"
MONGO_PASSWORD: "panda"
```

3. **检查认证**

```javascript
// 在 mongosh 中测试
use admin
db.auth("panda", "panda")
```

---

### Q1.4: 虚拟环境激活失败（Windows）

**问题描述**：
```
.\venv\Scripts\Activate.ps1 : 无法加载文件，因为在此系统上禁止运行脚本
```

**解决方案**：

以管理员身份运行 PowerShell：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

或使用 CMD：
```cmd
.\venv\Scripts\activate.bat
```

## 2. 数据相关问题

### Q2.1: 数据源配置后仍然获取不到数据

**排查步骤**：

1. **验证 Token/账号**

```python
# Tushare 验证
import tushare as ts
ts.set_token('your_token')
pro = ts.pro_api()
df = pro.stock_basic()  # 测试是否能获取数据
print(df.head())
```

2. **检查配置文件**

确认 `config.yaml` 中数据源配置正确：
```yaml
DATASOURCE: tushare
TS_TOKEN: "你的真实token"  # 注意：不要有多余空格
```

3. **检查积分/权限**

- Tushare 需要一定积分才能获取部分数据
- 米筐需要付费会员获取更多数据

---

### Q2.2: 数据清洗服务运行很慢

**原因分析**：
- 首次运行需要下载大量历史数据
- 网络速度限制
- 数据源 API 限制

**优化建议**：

1. **缩小时间范围**

```yaml
# config.yaml
HUB_START_DATE: 20230101  # 改为较近的日期
HUB_END_DATE: 20240101
```

2. **分批下载**

先下载最近一年的数据，验证系统正常后再扩展。

3. **使用缓存**

数据清洗服务会自动缓存已下载的数据，中断后重新运行会从断点继续。

---

### Q2.3: 数据库占用空间过大

**查看空间占用**：
```javascript
// mongosh
use panda
db.stats()
```

**清理建议**：

1. 删除不需要的历史数据
2. 只保留常用股票池的数据
3. 定期清理日志集合

```javascript
// 删除指定日期之前的数据
db.market_data.deleteMany({ date: { $lt: "20200101" } })
```

## 3. 因子开发问题

### Q3.1: 因子计算结果全是 NaN

**常见原因**：

1. **数据列名错误**
```python
# ❌ 错误
close = factors['CLOSE']  # 大写

# ✅ 正确
close = factors['close']  # 小写
```

2. **窗口期超过数据范围**
```python
# 如果数据只有 100 天，但窗口期是 200
volatility = self.STDDEV(returns, window=200)  # 全是 NaN
```

3. **计算中出现除零**
```python
# ❌ 可能除零
result = a / b

# ✅ 加入保护
result = a / (b + 1e-10)
```

**调试方法**：
```python
def calculate(self, factors):
    close = factors['close']
    print(f"数据行数: {len(close)}")
    print(f"NaN 比例: {close.isna().mean():.2%}")
    print(f"数据范围: {close.min()} ~ {close.max()}")
    
    # 继续计算...
```

### Q3.2: 因子类找不到（ImportError）

**问题描述**：
```
ImportError: cannot import name 'MyFactor' from 'my_factors'
```

**解决方案**：

1. **检查文件路径**

确保因子文件在正确位置：
```
my_factors/
├── __init__.py      # 必须有
└── my_factor.py
```

2. **检查 `__init__.py`**

```python
# my_factors/__init__.py
from .my_factor import MyFactor
```

3. **检查类名**

确保文件中的类名与导入的一致。

---

### Q3.3: 因子计算速度很慢

**优化建议**：

1. **避免循环**
```python
# ❌ 慢
for symbol in symbols:
    for date in dates:
        result[date, symbol] = calculate(data[date, symbol])

# ✅ 快（向量化）
result = data.groupby('symbol').apply(calculate)
```

2. **使用内置方法**
```python
# ❌ 自己实现滚动计算
for i in range(window, len(data)):
    result[i] = data[i-window:i].mean()

# ✅ 使用 pandas 内置
result = data.rolling(window).mean()
```

3. **减少数据复制**
```python
# ❌ 多次复制
temp1 = data.copy()
temp2 = temp1[mask].copy()

# ✅ 直接操作
result = data[mask]
```

---

### Q3.4: 如何在因子中使用自定义数据？

**方法**：通过 `factors` 字典传入

```python
# 准备自定义数据
custom_data = load_my_data()  # 你的数据加载函数

# 添加到 factors
factors['my_custom'] = custom_data

# 在因子中使用
class MyFactor(Factor):
    def calculate(self, factors):
        custom = factors.get('my_custom')
        if custom is None:
            raise ValueError("缺少自定义数据")
        return self.RANK(custom)
```

## 4. 分析结果问题

### Q4.1: IC 值特别小（接近 0）

**可能原因**：

1. 因子逻辑本身没有预测能力
2. 回测区间选择不当
3. 股票池不适合该因子

**排查步骤**：

1. 在不同市场环境下测试
2. 尝试不同的股票池
3. 分析因子与收益的散点图

---

### Q4.2: 分组收益不单调

**可能原因**：

1. **非线性关系**

因子值和收益不是简单的线性关系。

**解决**：
```python
# 尝试分段处理
def calculate(self, factors):
    raw = self.RANK(factors['close'])
    # 只取两端
    result = self.IF(raw > 0.3, raw, self.IF(raw < -0.3, raw, 0))
    return result
```

2. **极端值影响**

**解决**：去极值
```python
factor = factor.clip(-3, 3)  # 或使用更复杂的去极值方法
```

---

### Q4.3: 多空组合收益很低

**排查方向**：

1. **检查换手率**

换手率过高会侵蚀收益。

2. **考虑交易成本**

实际收益 = 理论收益 - 交易成本

3. **检查做空限制**

A 股做空限制较多，多空策略可能无法完全实现。

## 5. 性能优化问题

### Q5.1: 内存不足（MemoryError）

**优化方法**：

1. **减少数据量**
```python
# 只加载需要的列
df = df[['date', 'symbol', 'close', 'volume']]
```

2. **使用更小的数据类型**
```python
df['volume'] = df['volume'].astype('float32')
```

3. **分批处理**
```python
for chunk in pd.read_csv(file, chunksize=10000):
    process(chunk)
```

---

### Q5.2: 数据库查询慢

**优化方法**：

1. **创建索引**
```javascript
// mongosh
db.market_data.createIndex({ date: 1, symbol: 1 })
```

2. **只查询需要的字段**
```python
# 指定返回字段
cursor = collection.find({}, {'close': 1, 'volume': 1})
```

3. **使用分页查询**
```python
# 分页
cursor = collection.find().skip(page * size).limit(size)
```

## 6. Web 界面问题

### Q6.1: 页面无法访问

**排查步骤**：

1. **检查服务是否启动**
```bash
# 检查端口占用
netstat -an | grep 8000
```

2. **检查防火墙**

确保端口未被防火墙阻止。

3. **查看服务日志**

检查是否有错误信息。

---

### Q6.2: 图表不显示

**可能原因**：

1. 浏览器版本过旧
2. JavaScript 被禁用
3. 网络问题导致资源加载失败

**解决方案**：

1. 使用 Chrome/Firefox 最新版本
2. 清除浏览器缓存
3. 检查控制台错误信息（F12）

---

### Q6.3: 保存因子失败

**排查步骤**：

1. **检查因子代码语法**

确保代码没有语法错误。

2. **检查网络连接**

确保与后端服务的连接正常。

3. **检查权限**

确保有写入权限。
