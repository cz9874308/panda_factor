# PandaFactor 新手教程

欢迎来到 PandaFactor！🐼

这是一套专为**量化投资新手**设计的教程。无论你是否有编程基础，都能通过这套教程快速上手因子开发。

---

## 📖 这套教程能帮你学会什么？

完成这套教程后，你将能够：

- ✅ 理解什么是因子，以及因子分析的基本原理
- ✅ 搭建本地开发环境
- ✅ 编写自己的第一个因子
- ✅ 运行因子分析并解读结果
- ✅ 掌握因子开发的最佳实践

---

### 路径 A：完全新手（推荐）


### 路径 C：只想快速体验

```

```
