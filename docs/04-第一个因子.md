## 4.2 公式模式快速入门

### 4.2.1 基本语法

公式模式使用类似 Excel 的函数语法：

```
因子公式 = 函数1(函数2(数据列), 参数)
```

### 4.2.2 可用的数据列

| 数据列 | 含义 | 示例值 |
|--------|------|--------|
| `OPEN` | 开盘价 | 10.5 |
| `HIGH` | 最高价 | 10.8 |
| `LOW` | 最低价 | 10.2 |
| `CLOSE` | 收盘价 | 10.6 |
| `VOLUME` | 成交量 | 1000000 |
| `AMOUNT` | 成交额 | 10500000 |

### 4.2.3 常用函数

**排名函数**

| 函数 | 含义 | 示例 |
|------|------|------|
| `RANK(x)` | 横截面排名（归一化） | `RANK(CLOSE)` |

**时序函数**

| 函数 | 含义 | 示例 |
|------|------|------|
| `DELAY(x, n)` | 取 n 天前的值 | `DELAY(CLOSE, 5)` |
| `SUM(x, n)` | 过去 n 天的和 | `SUM(VOLUME, 10)` |
| `MEAN(x, n)` | 过去 n 天的均值 | `MEAN(CLOSE, 20)` |
| `STDDEV(x, n)` | 过去 n 天的标准差 | `STDDEV(CLOSE, 20)` |
| `MAX(x, n)` | 过去 n 天的最大值 | `MAX(HIGH, 10)` |
| `MIN(x, n)` | 过去 n 天的最小值 | `MIN(LOW, 10)` |

**计算函数**

| 函数 | 含义 | 示例 |
|------|------|------|
| `RETURNS(x)` | 计算收益率 | `RETURNS(CLOSE)` |
| `LOG(x)` | 自然对数 | `LOG(VOLUME)` |
| `ABS(x)` | 绝对值 | `ABS(RETURNS(CLOSE))` |

**条件函数**

| 函数 | 含义 | 示例 |
|------|------|------|
| `IF(cond, a, b)` | 条件选择 | `IF(CLOSE > OPEN, 1, 0)` |

### 4.2.4 实战：创建动量因子

**需求**：创建一个 20 日动量因子，衡量股票过去 20 天的涨跌幅。

**思路**：
1. 获取今日收盘价
2. 获取 20 天前的收盘价
3. 计算涨跌幅
4. 对所有股票排名

**公式**：

```
RANK((CLOSE / DELAY(CLOSE, 20)) - 1)
```

**分解理解**：

```
DELAY(CLOSE, 20)           → 20 天前的收盘价
CLOSE / DELAY(CLOSE, 20)   → 今日价格 / 20天前价格
... - 1                     → 转换为涨跌幅（如 1.1 → 0.1 表示涨 10%）
RANK(...)                   → 对所有股票排名
```

### 4.2.5 在 Web 界面使用公式

![公式编辑界面](./images/04-formula-editor.png)

1. 打开 PandaFactor Web 界面
2. 点击"新建因子"
3. 选择"公式模式"
4. 输入因子名称：`momentum_20d`
5. 输入公式：`RANK((CLOSE / DELAY(CLOSE, 20)) - 1)`
6. 点击"保存"

## 4.3 Python 模式详解

### 4.3.1 基本结构

所有 Python 因子都需要继承 `Factor` 基类：

```python
from panda_factor.generate import Factor

class MyFactor(Factor):
    """我的第一个因子"""
    
    def calculate(self, factors):
        """计算因子值
        
        Args:
            factors: 字典，包含所有基础数据
                    键：'open', 'high', 'low', 'close', 'volume', 'amount'
                    值：pd.Series，索引为 (date, symbol)
        
        Returns:
            pd.Series: 计算好的因子值
        """
        # 在这里编写计算逻辑
        close = factors['close']
        return self.RANK(close)
```

### 4.3.4 实战：创建完整因子

**需求**：创建一个"量价背离"因子，衡量价格上涨但成交量下降的股票。

**逻辑**：
- 如果价格上涨（收益率 > 0）但成交量下降（今日成交量 < 昨日），说明可能是"虚涨"
- 反之，如果价格下跌但成交量放大，说明可能是"恐慌性抛售"

**代码**：

```python
from panda_factor.generate import Factor

class VolumePrice Divergence(Factor):
    """量价背离因子
    
    衡量价格和成交量的背离程度。
    - 正值：价格涨但量缩（可能是弱势上涨）
    - 负值：价格跌但量增（可能是恐慌抛售）
    """
    
    def calculate(self, factors):
        # 获取数据
        close = factors['close']
        volume = factors['volume']
        
        # 计算收益率
        returns = self.RETURNS(close)
        
        # 计算成交量变化率
        volume_change = self.RETURNS(volume)
        
        # 计算背离程度
        # 收益率 * (-成交量变化率)
        # 价格涨 + 量缩 → 正 * 正 = 正
        # 价格跌 + 量增 → 负 * 负 = 负... 不对
        # 我们用：收益率 - 成交量变化率（归一化后）
        returns_rank = self.RANK(returns)
        volume_rank = self.RANK(volume_change)
        
        # 背离 = 价格排名 - 成交量排名
        # 价格排名高但成交量排名低 → 正值（量价背离）
        divergence = returns_rank - volume_rank
        
        return divergence
```

**IC 指标解读**：

| 指标 | 本例值 | 解读 |
|------|--------|------|
| IC 均值 | 0.0352 | 正值，说明因子有正向预测能力 |
| IC 标准差 | 0.1245 | 波动较大 |
| IR | 0.2828 | 低于 0.5，预测能力不太稳定 |
| IC > 0 比例 | 58.3% | 超过一半的时间预测正确 |

**分组收益解读**：

```
收益率
  ↑
  │                                   8.92%
  │                         5.67%    ████
  │               3.45%    ████      ████
  │     1.28%    ████      ████      ████
  │    ████      ████      ████      ████
  │    ████      ████      ████      ████
-2.35%─████──────────────────────────────────→ 分组
  第1组    第2组     第3组     第4组     第5组
```

分组收益呈现**单调递增**，说明因子有效：
- 因子值高的股票（第5组）收益更高
- 因子值低的股票（第1组）收益更低

### 4.5.3 判断因子是否有效

**有效因子的特征**：

- ✅ IC 均值 > 0.03（或 < -0.03）
- ✅ IR > 0.5
- ✅ 分组收益单调
- ✅ 多空组合收益显著

**本例结论**：
- IC 均值 0.0352 > 0.03 ✅
- IR 0.28 < 0.5 ❌（偏弱）
- 分组收益单调 ✅
- 多空收益 11.27% ✅

**整体判断**：这是一个**弱有效**的因子，有一定的预测能力，但稳定性不够。

## 4.6 常见问题

### Q1：因子计算结果全是 NaN？

**可能原因**：
- 数据列名拼写错误（应该是小写 `'close'` 而不是 `'CLOSE'`）
- 窗口期超过数据范围
- 计算过程中出现除零

**解决方法**：
```python
def calculate(self, factors):
    close = factors['close']  # 注意是小写
    # 检查数据
    print(f"数据行数: {len(close)}")
    print(f"NaN 数量: {close.isna().sum()}")
    ...
```

### Q2：IC 值特别小（接近 0）？

**可能原因**：
- 因子逻辑可能没有预测能力
- 参数设置不合理
- 数据问题

**解决方法**：
- 检查因子逻辑是否符合预期
- 尝试调整参数（如窗口期）
- 使用更长的回测区间

### Q3：分组收益不单调？

**可能原因**：
- 因子与收益的关系可能是非线性的
- 因子可能只在特定市场环境下有效
- 数据量不足

**解决方法**：
- 尝试对因子做变换（如取对数）
- 分析不同市场环境下的表现
- 增加回测区间

## 🎯 课后练习

尝试创建以下因子并分析效果：

**练习 1：反转因子（简单）**

```
RANK(-RETURNS(CLOSE))
```

逻辑：过去表现差的股票未来可能反弹。

**练习 2：波动率因子（中等）**

```python
class VolatilityFactor(Factor):
    def calculate(self, factors):
        close = factors['close']
        returns = self.RETURNS(close)
        volatility = self.STDDEV(returns, window=20)
        return -self.RANK(volatility)  # 负号表示低波动率更好
```

**练习 3：成交量因子（中等）**

```python
class VolumeFactor(Factor):
    def calculate(self, factors):
        volume = factors['volume']
        # 今日成交量 / 过去20日平均成交量
        avg_volume = volume.groupby(level='symbol').rolling(20).mean().droplevel(0)
        volume_ratio = volume / avg_volume
        return self.RANK(volume_ratio)
```
