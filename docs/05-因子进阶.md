## 5.1 经典因子案例

### 5.1.1 Alpha101 因子

Alpha101 是由 WorldQuant 发布的 101 个量化因子，是学习因子开发的经典教材。

#### Alpha#1：反转因子

```python
class Alpha001(Factor):
    """Alpha#1: 成交量加权的反转因子
    
    逻辑：最近收益率为负的股票，如果成交量排名靠后，可能会反弹
    """
    
    def calculate(self, factors):
        close = factors['close']
        volume = factors['volume']
        
        # 计算收益率
        returns = self.RETURNS(close)
        
        # 条件：收益率 < 0
        condition = returns < 0
        
        # 成交量排名
        volume_rank = self.RANK(volume)
        
        # 如果收益率为负，返回成交量排名的平方；否则返回排名
        result = self.IF(
            condition,
            volume_rank ** 2,  # 负收益时：放大成交量影响
            volume_rank
        )
        
        return -result  # 取负号，成交量排名低的股票更可能反弹
```

#### Alpha#6：相关性因子

```python
class Alpha006(Factor):
    """Alpha#6: 开盘价与成交量的相关性
    
    逻辑：开盘价和成交量的相关性反映市场情绪
    """
    
    def calculate(self, factors):
        open_price = factors['open']
        volume = factors['volume']
        
        # 计算10日滚动相关系数
        corr = self.CORRELATION(open_price, volume, window=10)
        
        # 对相关系数排名取负
        return -self.RANK(corr)
```

#### Alpha#12：动量信号因子

```python
class Alpha012(Factor):
    """Alpha#12: 价格变化的符号 * 成交量变化
    
    逻辑：价格上涨时成交量放大是健康的上涨
    """
    
    def calculate(self, factors):
        close = factors['close']
        volume = factors['volume']
        
        # 价格变化的符号
        price_change = close - self.DELAY(close, 1)
        sign_price = self.IF(price_change > 0, 1, self.IF(price_change < 0, -1, 0))
        
        # 成交量变化
        volume_change = volume - self.DELAY(volume, 1)
        
        # 符号 * 成交量变化
        return -sign_price * volume_change
```

### 5.1.2 价值因子

#### 市盈率因子（PE）

```python
class PEFactor(Factor):
    """市盈率因子
    
    逻辑：低市盈率的股票可能被低估
    
    注意：需要财务数据支持
    """
    
    def calculate(self, factors):
        close = factors['close']
        # 假设 eps 在 factors 中
        eps = factors.get('eps')
        
        if eps is None:
            # 如果没有 EPS 数据，返回空
            return close * 0
        
        # 市盈率 = 价格 / 每股收益
        pe = close / eps
        
        # PE 越低越好，取负排名
        return -self.RANK(pe)
```

#### 市净率因子（PB）

```python
class PBFactor(Factor):

        pb = close / bps

        return -self.RANK(pb)
```

### 5.1.4 技术因子

#### RSI 因子

```python
class RSIFactor(Factor):
    """RSI（相对强弱指标）因子
    
    逻辑：RSI 过高可能超买，过低可能超卖
    """
    
    def calculate(self, factors):
        close = factors['close']
        
        # 计算价格变化
        delta = close - self.DELAY(close, 1)
        
        # 分离涨跌
        gain = self.IF(delta > 0, delta, 0)
        loss = self.IF(delta < 0, -delta, 0)
        
        # 14日平均涨跌
        avg_gain = gain.groupby(level='symbol').rolling(14).mean().droplevel(0)
        avg_loss = loss.groupby(level='symbol').rolling(14).mean().droplevel(0)
        
        # RSI 计算
        rs = avg_gain / (avg_loss + 1e-10)  # 避免除零
        rsi = 100 - (100 / (1 + rs))
        
        # RSI 低于 30 可能超卖（买入信号）
        # RSI 高于 70 可能超买（卖出信号）
        # 返回负 RSI，RSI 低的排名高
        return -self.RANK(rsi)
```

#### MACD 因子

```python
class MACDFactor(Factor):
    """MACD 因子
    
    逻辑：MACD 金叉看涨，死叉看跌
    """
    
    def calculate(self, factors):
        close = factors['close']
        
        # 计算 EMA
        def ema(series, span):
            return series.groupby(level='symbol').apply(
                lambda x: x.ewm(span=span, adjust=False).mean()
            ).droplevel(0)
        
        # 12日和26日 EMA
        ema12 = ema(close, 12)
        ema26 = ema(close, 26)
        
        # DIF = 快线 - 慢线
        dif = ema12 - ema26
        
        # DEA = DIF 的 9 日 EMA
        dea = ema(dif, 9)
        
        # MACD = (DIF - DEA) * 2
        macd = (dif - dea) * 2
        
        # MACD 为正表示多头，为负表示空头
        return self.RANK(macd)
```

## 5.2 因子组合

### 5.2.1 为什么要组合因子？

单一因子的问题：
- 预测能力有限
- 可能只在特定市场环境下有效
- 风险集中

因子组合的优势：
- 综合多种信息来源
- 提高预测稳定性
- 分散风险

### 5.2.2 组合方法

#### 方法一：等权重组合

最简单的方法，对每个因子赋予相同权重。

```python
class EqualWeightCombo(Factor):
    """等权重因子组合"""
    
    def calculate(self, factors):
        close = factors['close']
        volume = factors['volume']
        
        # 计算各个子因子
        # 动量因子
        returns = self.RETURNS(close)
        momentum = self.RANK(self.SUM(returns, 20))
        
        # 反转因子
        reversal = -self.RANK(returns)
        
        # 波动率因子（低波动）
        volatility = -self.RANK(self.STDDEV(returns, 20))
        
        # 成交量因子
        vol_rank = self.RANK(volume)
        
        # 等权重组合
        combo = (momentum + reversal + volatility + vol_rank) / 4
        
        return combo
```

#### 方法二：IC 加权组合

根据历史 IC 表现分配权重。

```python
class ICWeightedCombo(Factor):
    """IC 加权因子组合
    
    IC 高的因子权重大，IC 低的因子权重小
    """
    
    def calculate(self, factors):
        close = factors['close']
        volume = factors['volume']
        
        # 计算子因子
        returns = self.RETURNS(close)
        momentum = self.RANK(self.SUM(returns, 20))
        reversal = -self.RANK(returns)
        volatility = -self.RANK(self.STDDEV(returns, 20))
        
        # 假设历史 IC（实际应该从分析结果获取）
        ic_momentum = 0.04
        ic_reversal = 0.02
        ic_volatility = 0.03
        
        # 计算权重（IC 的绝对值归一化）
        total_ic = abs(ic_momentum) + abs(ic_reversal) + abs(ic_volatility)
        w_momentum = abs(ic_momentum) / total_ic
        w_reversal = abs(ic_reversal) / total_ic
        w_volatility = abs(ic_volatility) / total_ic
        
        # IC 加权组合
        combo = (
            w_momentum * momentum +
            w_reversal * reversal +
            w_volatility * volatility
        )
        
        return combo
```

#### 方法三：正交化组合

去除因子之间的相关性，保留独立信息。

```
原始因子             正交化后
┌──────────┐        ┌──────────┐
│  因子A   │  ───►  │  因子A'  │  （保留）
└──────────┘        └──────────┘
      │
      │ 相关
      ▼
┌──────────┐        ┌──────────┐
│  因子B   │  ───►  │  因子B'  │  （去除与A相关的部分）
└──────────┘        └──────────┘
```

```python
class OrthogonalCombo(Factor):
    """正交化因子组合"""
    
    def calculate(self, factors):
        close = factors['close']
        
        returns = self.RETURNS(close)
        
        # 计算子因子
        factor_a = self.RANK(self.SUM(returns, 20))  # 动量
        factor_b = -self.RANK(returns)               # 反转
        
        # 正交化：从 B 中去除与 A 相关的部分
        # B' = B - corr(A,B) * A
        def orthogonalize(fa, fb):
            # 按日期分组计算相关系数
            result = fb.copy()
            for date in fb.index.get_level_values('date').unique():
                mask = fb.index.get_level_values('date') == date
                a_day = fa[mask]
                b_day = fb[mask]
                
                # 计算相关系数
                corr = a_day.corr(b_day)
                
                # 正交化
                result[mask] = b_day - corr * a_day
            
            return result
        
        factor_b_orth = orthogonalize(factor_a, factor_b)
        
        # 组合正交化后的因子
        combo = factor_a + factor_b_orth
        
        return self.RANK(combo)
```

### 5.2.3 组合原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **低相关性** | 选择相关性低的因子组合 | 动量 + 价值（通常负相关） |
| **多来源** | 来自不同数据源 | 量价 + 财务 + 技术 |
| **稳定优先** | 优先选择 IR 高的因子 | 剔除 IR < 0.3 的因子 |
| **简单为美** | 组合因子不宜过多 | 3-5 个因子为宜 |

## 5.3 因子优化技巧

### 5.3.1 数据预处理

#### 去极值

```python
def winsorize(series, n_std=3):
    """去极值：将超出 n 倍标准差的值截断"""
    
    def process_group(group):
        mean = group.mean()
        std = group.std()
        upper = mean + n_std * std
        lower = mean - n_std * std
        return group.clip(lower, upper)
    
    return series.groupby('date').apply(process_group)
```

#### 标准化

```python
def standardize(series):
    """标准化：使每天的因子值均值为0，标准差为1"""
    
    def process_group(group):
        mean = group.mean()
        std = group.std()
        if std == 0:
            return group * 0
        return (group - mean) / std
    
    return series.groupby('date').apply(process_group)
```

#### 中性化

```python
def neutralize(factor, industry):
    """行业中性化：去除行业影响"""
    
    result = factor.copy()
    
    for date in factor.index.get_level_values('date').unique():
        mask = factor.index.get_level_values('date') == date
        factor_day = factor[mask]
        industry_day = industry[mask]
        
        # 按行业计算均值
        industry_mean = factor_day.groupby(industry_day).transform('mean')
        
        # 去除行业均值
        result[mask] = factor_day - industry_mean
    
    return result
```

```

┌────────┬──────────┬──────────┐
│ 窗口期 │  IC均值  │    IR    │
├────────┼──────────┼──────────┤

```

**优化方法**：

```python
# 遍历不同窗口期
windows = [5, 10, 20, 40, 60]
results = []

for window in windows:

# 选择 IR 最高的窗口期
best_window = max(results, key=lambda x: x['ir'])['window']
```

### 5.3.3 过拟合防范

#### 样本外测试

```
┌─────────────────────────────────────────────────────┐
│                    全部数据                          │
├───────────────────────────┬─────────────────────────┤
│      样本内（70%）        │     样本外（30%）       │
│   用于开发和优化因子      │   用于验证因子效果      │
└───────────────────────────┴─────────────────────────┘
```

**关键原则**：
- 在样本内优化参数
- 在样本外验证效果
- 样本外效果大幅下降 → 过拟合

#### 交叉验证

```python
def cross_validate(factor_func, data, n_folds=5):
    """时序交叉验证"""
    
    dates = data.index.get_level_values('date').unique()
    fold_size = len(dates) // n_folds
    
    results = []
    for i in range(n_folds):
        # 划分训练集和测试集
        test_start = i * fold_size
        test_end = (i + 1) * fold_size
        
        test_dates = dates[test_start:test_end]
        train_dates = dates[:test_start].union(dates[test_end:])
        
        # 在测试集上评估
        test_data = data[data.index.get_level_values('date').isin(test_dates)]
        factor = factor_func(test_data)
        ic = calculate_ic(factor, future_returns)
        
        results.append(ic.mean())
    
    return np.mean(results), np.std(results)
```

## 5.4 常见陷阱与避免

### 5.4.1 未来数据泄露

**问题**：使用了未来才能获得的数据

```python
# ❌ 错误：使用未来数据
def bad_factor(factors):
    close = factors['close']
    # 错误！使用了未来5天的最高价
    future_high = close.groupby('symbol').shift(-5)
    return close / future_high

# ✅ 正确：只使用历史数据
def good_factor(factors):
    close = factors['close']
    # 使用过去5天的最高价
    past_high = close.groupby('symbol').rolling(5).max().droplevel(0)
    return close / past_high
```
