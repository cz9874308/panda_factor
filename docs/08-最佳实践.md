## 1. 因子开发最佳实践

### 1.1 因子设计原则

#### 原则一：逻辑优先于数据挖掘

```
✅ 好的因子开发流程：
   想法 → 逻辑验证 → 数据验证 → 优化

❌ 不好的因子开发流程：
   数据挖掘 → 找到相关性 → 编造逻辑
```

**示例**：

```python
# ✅ 有明确逻辑的因子
class QualityFactor(Factor):
    """质量因子：ROE 高的公司盈利能力强，股价表现更好
    
    经济学逻辑：
    - ROE 反映公司利用股东资本创造利润的能力
    - 高 ROE 意味着公司有竞争优势
    - 长期来看，好公司的股价会反映其基本面
    """
    def calculate(self, factors):
        roe = factors['roe']
        return self.RANK(roe)

# ❌ 纯数据挖掘的因子
class RandomFactor(Factor):
    """因子A：收盘价第3位数字 + 成交量倒数第2位
    
    没有任何经济学逻辑，纯粹是数据巧合
    """
    pass
```

#### 原则二：简单优于复杂

```
因子复杂度  │
            │    ╱──── 过拟合风险
            │  ╱
            │╱
            ├─────────────────
            │╲
            │  ╲
            │    ╲──── 因子效果
            └─────────────────────→ 复杂度
```

**示例**：

```python
# ✅ 简单有效
class SimpleMomentum(Factor):
    def calculate(self, factors):
        close = factors['close']
        return self.RANK(close / self.DELAY(close, 20) - 1)

# ❌ 过度复杂
class ComplexMomentum(Factor):
    def calculate(self, factors):
        close = factors['close']
        # 20+ 个参数，10+ 个条件判断...
        # 很可能是过拟合
```

#### 原则三：样本外验证

```
时间轴
├──────────────────────┼──────────────────┤
│   样本内（开发用）   │   样本外（验证用） │
│      2018-2022       │      2023-2024    │
└──────────────────────┴──────────────────┘
```

**关键要求**：
- 在样本内开发和优化因子
- 在样本外验证因子效果
- 样本外效果显著下降 → 过拟合警告

### 1.2 常见陷阱与避免

#### 陷阱一：未来数据泄露

```python
# ❌ 使用了未来数据
def bad_factor(factors):
    close = factors['close']
    # 使用了未来 5 天的数据！
    future_return = (self.DELAY(close, -5) - close) / close
    return future_return

# ✅ 只使用历史数据
def good_factor(factors):
    close = factors['close']
    # 使用过去 5 天的数据
    past_return = (close - self.DELAY(close, 5)) / self.DELAY(close, 5)
    return past_return
```

#### 陷阱二：存活偏差

```
❌ 只看现在还存在的股票
   - 忽略了已退市的失败公司
   - 高估了因子效果

✅ 使用时点数据
   - 每个时点使用当时的股票池
   - 包含后来退市的股票
```

#### 陷阱三：多重检验问题

```
测试 100 个因子 → 期望 5 个偶然显著（5% 显著性水平）

解决方案：
1. 调整显著性阈值（Bonferroni 校正）
2. 要求更高的 IC/IR
3. 强调逻辑合理性
```

### 1.3 因子命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 动量因子 | momentum_Nd | momentum_20d |

## 2. 代码规范

### 2.1 因子类结构

```python
"""
模块说明文档

描述这个文件包含的因子类型和用途。
"""

from panda_factor.generate import Factor


class MyFactor(Factor):
    """因子名称
    
    一句话描述因子的核心逻辑。
    
    经济学逻辑
    ----------
    解释为什么这个因子应该有效。
    
    参数说明
    --------
    如果有可调参数，在这里说明。
    
    使用示例
    --------
    >>> factor = MyFactor()
    >>> result = factor.calculate(factors)
    
    参考文献
    --------
    如果基于论文或其他资料，在这里引用。
    """
    
    def calculate(self, factors):
        """计算因子值
        
        Args:
            factors: 包含基础数据的字典
        
        Returns:
            pd.Series: 因子值，索引为 (date, symbol)
        """
        # 1. 获取数据
        close = factors['close']
        
        # 2. 计算逻辑
        returns = self.RETURNS(close)
        
        # 3. 返回结果
        return self.RANK(returns)
```

### 2.2 代码风格

#### 清晰的变量命名

```python
# ❌ 不好的命名
x = factors['close']
y = x / self.DELAY(x, 20) - 1
z = self.RANK(y)

# ✅ 好的命名
close = factors['close']
returns_20d = close / self.DELAY(close, 20) - 1
momentum_rank = self.RANK(returns_20d)
```

#### 适当的注释

```python
def calculate(self, factors):
    close = factors['close']
    volume = factors['volume']
    
    # 计算价格动量（20日收益率）
    price_momentum = self.RETURNS(close)
    
    # 计算成交量变化（相对于20日均值）
    vol_ma = volume.groupby('symbol').rolling(20).mean().droplevel(0)
    vol_ratio = volume / vol_ma
    
    # 组合：价格上涨 + 成交量放大 = 健康的上涨
    # 使用乘法组合，两者同时为正时信号更强
    combined = self.RANK(price_momentum) * self.RANK(vol_ratio)
    
    return combined
```

### 2.3 错误处理

```python
def calculate(self, factors):
    # 检查必需数据
    required = ['close', 'volume']
    for col in required:
        if col not in factors:
            raise ValueError(f"缺少必需数据: {col}")
    
    close = factors['close']
    
    # 检查数据有效性
    if close.isna().all():
        raise ValueError("close 数据全为 NaN")
    
    # 处理可能的除零
    denominator = self.DELAY(close, 20)
    denominator = denominator.replace(0, np.nan)  # 避免除零
    
    returns = close / denominator - 1
    
    return self.RANK(returns)
```

## 3. 测试与验证

### 3.1 单元测试

```python
import unittest
import pandas as pd
import numpy as np
from my_factors import MomentumFactor


class TestMomentumFactor(unittest.TestCase):
    
    def setUp(self):
        """准备测试数据"""
        dates = pd.date_range('2024-01-01', periods=30)
        symbols = ['A', 'B', 'C']
        
        index = pd.MultiIndex.from_product(
            [dates, symbols], 
            names=['date', 'symbol']
        )
        
        # 创建模拟数据
        np.random.seed(42)
        self.factors = {
            'close': pd.Series(np.random.randn(90).cumsum() + 100, index=index),
            'volume': pd.Series(np.random.randint(1000, 10000, 90), index=index),
        }
    
    def test_basic_calculation(self):
        """测试基本计算"""
        factor = MomentumFactor()
        result = factor.calculate(self.factors)
        
        # 检查返回类型
        self.assertIsInstance(result, pd.Series)
        
        # 检查索引
        self.assertEqual(result.index.names, ['date', 'symbol'])
        
        # 检查数值范围（RANK 后应该在 [-0.5, 0.5]）
        self.assertTrue(result.max() <= 0.5)
        self.assertTrue(result.min() >= -0.5)
    
    def test_no_future_data(self):
        """测试没有使用未来数据"""
        factor = MomentumFactor()
        
        # 只给部分数据
        partial_factors = {
            k: v.iloc[:60] for k, v in self.factors.items()
        }
        result1 = factor.calculate(partial_factors)
        
        # 给全部数据
        result2 = factor.calculate(self.factors)
        
        # 前60个点的结果应该相同
        common_index = result1.index
        pd.testing.assert_series_equal(
            result1, 
            result2.loc[common_index],
            check_names=False
        )


if __name__ == '__main__':
    unittest.main()
```

### 3.2 回测验证清单

在使用因子之前，完成以下检查：

```
□ 基础检查
  □ 因子值没有全部为 NaN
  □ 因子值分布合理（无极端异常值）
  □ 因子值在不同日期间有变化

□ IC 检查
  □ IC 均值 > 0.03 或 < -0.03
  □ IR > 0.3
  □ IC > 0 比例 > 55%

□ 分组检查
  □ 分组收益单调（或近似单调）
  □ 第1组和第N组收益差异显著

□ 稳定性检查
  □ 在不同时期表现一致
  □ 在不同股票池表现一致
  □ 对参数变化不敏感

□ 风险检查
  □ 最大回撤可接受
  □ 波动率合理
  □ 换手率不过高
```

## 总结

### 核心原则

1. **逻辑第一**：因子要有明确的经济学逻辑
2. **简单有效**：简单的因子往往更稳健
3. **严格验证**：样本外测试是必须的
4. **持续监控**：因子效果会随时间变化
5. **不断学习**：量化投资是一个持续学习的过程

### 成功因子的特征

```
┌─────────────────────────────────────────────────────┐
│                    成功的因子                        │
├─────────────────────────────────────────────────────┤
│  ✅ 有清晰的经济学逻辑                              │
│  ✅ 在样本外仍然有效                                │
│  ✅ 对参数变化不敏感                                │
│  ✅ 在不同市场环境下表现稳定                        │
│  ✅ 与现有因子相关性低（提供增量信息）              │
└─────────────────────────────────────────────────────┘
```
