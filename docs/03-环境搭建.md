## 3.2 安装 Python

PandaFactor 需要 **Python 3.9+** 环境。

### Windows 用户

**方法一：官网下载（推荐新手）**

1. 访问 Python 官网：https://www.python.org/downloads/
2. 下载 Python 3.10 或 3.11 版本
3. 运行安装程序

![Python 安装界面](./images/03-python-install.png)

**重要设置**：
- ✅ 勾选 "Add Python to PATH"
- ✅ 选择 "Customize installation"
- ✅ 勾选 "pip"

4. 验证安装：

```powershell
# 打开 PowerShell，输入：
python --version
# 应该显示：Python 3.10.x 或 3.11.x

pip --version
# 应该显示：pip 23.x.x
```

**方法二：Anaconda（推荐有经验用户）**

1. 下载 Anaconda：https://www.anaconda.com/download
2. 安装后创建虚拟环境：

```powershell
conda create -n panda python=3.10
conda activate panda
```

### macOS 用户

**使用 Homebrew（推荐）**：

```bash
# 安装 Homebrew（如果没有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Python
brew install python@3.10

# 验证
python3 --version
```

### Linux 用户

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3.10 python3.10-venv python3-pip

# 验证
python3 --version
```

## 3.3 安装 MongoDB

PandaFactor 使用 MongoDB 存储市场数据和因子数据。

### Windows 用户

**方法一：MSI 安装包（推荐新手）**

1. 访问 MongoDB 下载页面：https://www.mongodb.com/try/download/community
2. 选择版本：
   - Version: 6.0 或 7.0
   - Platform: Windows
   - Package: MSI

![MongoDB 下载页面](./images/03-mongodb-download.png)

3. 运行安装程序：
   - 选择 "Complete" 安装
   - ✅ 勾选 "Install MongoDB as a Service"
   - ✅ 勾选 "Install MongoDB Compass"（可视化工具）

4. 验证安装：

```powershell
# MongoDB 服务应该已经自动启动
# 打开 MongoDB Compass 连接测试
```

**方法二：Docker（推荐有经验用户）**

```powershell
# 拉取镜像
docker pull mongo:6.0

# 启动容器
docker run -d --name mongodb -p 27017:27017 `
  -e MONGO_INITDB_ROOT_USERNAME=panda `
  -e MONGO_INITDB_ROOT_PASSWORD=panda `
  mongo:6.0
```

### macOS 用户

```bash
# 使用 Homebrew
brew tap mongodb/brew
brew install mongodb-community@6.0

# 启动服务
brew services start mongodb-community@6.0

# 验证
mongosh
```

### Linux 用户

```bash
# Ubuntu 22.04
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list
sudo apt update
sudo apt install -y mongodb-org

# 启动服务
sudo systemctl start mongod
sudo systemctl enable mongod

# 验证
mongosh
```

### 配置 MongoDB 用户（重要）

首次安装后，需要创建数据库用户：

```javascript
// 连接到 MongoDB
mongosh

// 切换到 admin 数据库
use admin

// 创建管理员用户
db.createUser({
  user: "panda",
  pwd: "panda",
  roles: [
    { role: "userAdminAnyDatabase", db: "admin" },
    { role: "readWriteAnyDatabase", db: "admin" }
  ]
})

// 退出
exit
```

## 3.4 克隆项目代码

### 安装 Git

如果还没有安装 Git：

- **Windows**: https://git-scm.com/download/win
- **macOS**: `brew install git`
- **Linux**: `sudo apt install git`


## 3.5 安装依赖包

### 创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows PowerShell:
.\venv\Scripts\Activate.ps1

# Windows CMD:
.\venv\Scripts\activate.bat

# macOS/Linux:
source venv/bin/activate
```

激活成功后，命令行前面会显示 `(venv)`。

### 安装依赖

```bash
# 安装项目依赖
pip install -r requirements.txt

# 安装各子模块
pip install -e panda_common/
pip install -e panda_data/
pip install -e panda_factor/
pip install -e panda_factor_server/
```

### 常见问题解决

**问题 1：pip 安装超时**

```bash
# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**问题 2：编译错误（Windows）**

部分依赖包需要 C++ 编译器。安装 Visual Studio Build Tools：
https://visualstudio.microsoft.com/visual-cpp-build-tools/

**问题 3：numpy/scipy 安装失败**

```bash
# 先单独安装
pip install numpy scipy pandas
```

## 3.6 配置系统参数

### 配置文件位置

主配置文件：`panda_common/panda_common/config.yaml`

### 必须配置的项目

用文本编辑器打开配置文件，修改以下内容：

```yaml
# 1. MongoDB 连接配置
MONGO_USER: "panda"           # 你创建的用户名
MONGO_PASSWORD: "panda"       # 你设置的密码
MONGO_URI: "127.0.0.1:27017"  # MongoDB 地址
MONGO_DB: "panda"             # 数据库名

# 2. MongoDB 模式（新手用单节点模式）
MONGO_TYPE: "single"          # 改为 single

# 3. 数据源配置（至少配置一个）
# 米筐（RiceQuant）
MUSER: "你的米筐账号"
MPASSWORD: "你的米筐密码"

# 或 Tushare
TS_TOKEN: "你的Tushare Token"

# 或 迅投
XT_TOKEN: "你的迅投Token"
```

### 获取数据源账号

PandaFactor 支持多个数据源，至少需要配置一个：

| 数据源 | 注册地址 | 免费额度 |
|--------|----------|----------|
| 米筐 RiceQuant | https://www.ricequant.com | 有限免费 |
| Tushare | https://tushare.pro | 需要积分 |
| 迅投 XtQuant | https://www.thinktrader.net | 有限免费 |

**新手推荐**：先注册 Tushare，获取 Token 后配置到 `TS_TOKEN`。

### 完整配置示例

```yaml
# 时间配置
HUB_START_DATE: 20200101
HUB_END_DATE: 20250101
UPDATE_TIME: '20:00'

# 数据源（配置你有账号的）
DATASOURCE: tushare
TS_TOKEN: "你的token放这里"

# MongoDB（单节点模式）
MONGO_USER: "panda"
MONGO_PASSWORD: "panda"
MONGO_URI: "127.0.0.1:27017"
MONGO_DB: "panda"
MONGO_TYPE: "single"

# 日志
LOG_LEVEL: "INFO"
```

## 🔧 故障排除

### 常见问题速查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| `python` 命令找不到 | 未添加到 PATH | 重新安装，勾选 "Add to PATH" |
| MongoDB 连接失败 | 服务未启动 | 启动 MongoDB 服务 |
| 导入模块失败 | 未安装子模块 | `pip install -e panda_xxx/` |
| 权限错误 | MongoDB 用户配置 | 检查用户名密码 |
