## 1.1 PandaFactor 是什么？

### 一句话定义

> **PandaFactor** 是一个量化因子开发和分析平台，帮助你快速创建、测试和评估投资因子。

### 通俗理解

想象你在挑选股票，你可能会问：

- "哪些股票最近涨得好？"（动量因子）
- "哪些股票的市盈率比较低？"（价值因子）
- "哪些股票的成交量突然放大？"（量价因子）

这些"挑选标准"在量化投资中就叫做**因子**。

PandaFactor 帮你做的事情就是：

```
定义因子 → 计算因子值 → 测试因子效果 → 展示分析结果
```

### 能解决什么问题？

| 问题 | PandaFactor 如何帮助 |
|------|----------------------|
| 我有一个选股想法，不知道效果如何 | 快速回测验证 |
| 手动计算因子太麻烦 | 自动计算所有股票的因子值 |
| 不知道因子好不好 | 提供 IC、分组收益等专业指标 |
| 想看可视化结果 | 内置多种分析图表 |

### 适合谁使用？

- ✅ 量化投资爱好者
- ✅ 想要学习因子开发的新手
- ✅ 需要快速验证想法的研究员
- ✅ 个人交易者

## 1.2 最简示例（3 行代码）

假设你想创建一个简单的"动量因子"——衡量股票过去 20 天的涨跌幅。

### 公式模式（最简单）

```python
RANK((CLOSE / DELAY(CLOSE, 20)) - 1)
```

这行代码的含义：
- `CLOSE`：当日收盘价
- `DELAY(CLOSE, 20)`：20 天前的收盘价
- `(CLOSE / DELAY(CLOSE, 20)) - 1`：计算 20 日收益率
- `RANK(...)`：对所有股票的收益率进行排名

就这么简单！一行公式就定义了一个因子。

### Python 模式（更灵活）

```python
class MomentumFactor(Factor):
    def calculate(self, factors):
        close = factors['close']
        returns = (close / DELAY(close, 20)) - 1
        return RANK(returns)
```

Python 模式适合更复杂的因子逻辑。

## 1.3 Web 界面体验

PandaFactor 提供了一个 Web 界面，让你可以：

- 📝 在线编写因子代码
- ▶️ 一键运行分析
- 📊 查看可视化结果
- 💾 保存和管理因子

### 界面预览

![PandaFactor 主界面](./images/01-main-interface.png)

**主界面**包含以下区域：
1. **因子列表**：左侧显示你创建的所有因子
2. **代码编辑区**：中间是因子代码编辑器
3. **参数设置**：右侧可以设置回测参数
4. **结果展示**：下方显示分析结果和图表

### 分析结果示例

![分析结果页面](./images/01-analysis-results.png)

运行分析后，你会看到：
- **IC 时序图**：因子预测能力随时间的变化
- **分组收益图**：按因子值分组后各组的收益表现
- **统计指标表**：IC 均值、IR、胜率等关键指标

## 1.4 系统架构（了解即可）

PandaFactor 的工作流程：

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  你的因子   │ ─► │  数据读取   │ ─► │  因子计算   │ ─► │  分析回测   │
│  代码/公式  │    │  市场数据   │    │  因子值     │    │  IC/分组等  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                                │
                                                                ▼
                                                         ┌─────────────┐
                                                         │  结果展示   │
                                                         │  图表/报告  │
                                                         └─────────────┘
```

你只需要关心第一步：**写好你的因子代码**。剩下的事情，PandaFactor 会自动完成。
