## 📖 课程概览

## 6.1 分析报告全解

### 6.1.1 报告结构

一份完整的因子分析报告通常包含：

```
┌─────────────────────────────────────────────────────┐
│                   因子分析报告                       │
├─────────────────────────────────────────────────────┤
│  1. 概览信息                                         │
│     - 因子名称、回测区间、参数设置                   │
├─────────────────────────────────────────────────────┤
│  2. IC 分析                                          │
│     - IC 统计指标                                    │
│     - IC 时序图                                      │
│     - IC 分布图                                      │
├─────────────────────────────────────────────────────┤
│  3. 分组分析                                         │
│     - 分组收益统计                                   │
│     - 分组累计收益曲线                               │
│     - 分组换手率                                     │
├─────────────────────────────────────────────────────┤
│  4. 收益归因                                         │
│     - 多空组合收益                                   │
│     - 超额收益分析                                   │
├─────────────────────────────────────────────────────┤
│  5. 风险分析                                         │
│     - 最大回撤                                       │
│     - 夏普比率                                       │
│     - 波动率                                         │
└─────────────────────────────────────────────────────┘
```

### 6.1.2 关键指标速查表

| 指标 | 优秀 | 良好 | 一般 | 较差 |
|------|------|------|------|------|
| IC 均值 | > 0.05 | 0.03~0.05 | 0.02~0.03 | < 0.02 |
| IR | > 1.0 | 0.5~1.0 | 0.3~0.5 | < 0.3 |
| IC > 0 比例 | > 60% | 55%~60% | 50%~55% | < 50% |
| 年化收益（多空） | > 20% | 10%~20% | 5%~10% | < 5% |
| 最大回撤 | < 10% | 10%~20% | 20%~30% | > 30% |
| 夏普比率 | > 2.0 | 1.0~2.0 | 0.5~1.0 | < 0.5 |

### 6.2.2 IC 时序图解读

![IC 时序图](./images/06-ic-timeseries.png)

IC 时序图展示因子预测能力随时间的变化：

```
IC值
 0.3 │         *                              *
     │    *         *       *           *
 0.2 │  *   *    *    *      *    *        *
     │*       *        *       *    *   *
 0.1 │──────────────────────────────────────────── 均值线
     │                          *
   0 │─────────────────────────────────────────────
     │      *              *
-0.1 │           *    *
     │                       *
-0.2 │
     └────────────────────────────────────────────→ 时间
       2023-01        2023-07        2024-01
```

**解读要点**：

| 特征 | 解读 | 建议 |
|------|------|------|
| IC 持续为正 | 因子稳定有效 | 可以使用 |
| IC 在 0 附近波动 | 因子弱有效或无效 | 谨慎使用 |
| IC 有明显趋势 | 因子效果在变化 | 关注因子衰减 |
| IC 突然变化 | 市场环境变化 | 分析原因 |

![IC 分布直方图](./images/06-ic-distribution.png)

### 6.3.1 分组收益柱状图

![分组收益柱状图](./images/06-group-returns.png)

```
年化收益率
    │
20% │                                   ████
    │                         ████      ████
15% │               ████      ████      ████
    │     ████      ████      ████      ████
10% │     ████      ████      ████      ████
    │     ████      ████      ████      ████
 5% │     ████      ████      ████      ████
    │     ████      ████      ████      ████
 0% │─────────────────────────────────────────
    │████
-5% │████
    └──────────────────────────────────────────→
     第1组   第2组    第3组    第4组    第5组
    (因子值最小)                    (因子值最大)

**解读要点**：

| 模式 | 含义 | 因子类型 |
|------|------|----------|
| 单调递增 | 因子值越大收益越高 | 正向因子 |
| 单调递减 | 因子值越小收益越高 | 负向因子 |
| U 型 | 极端值收益高 | 非线性关系 |
| 无规律 | 因子无效 | - |

```
换手率
    │
80% │████
    │████

    │████  ████

**换手率的意义**：
- 换手率高 → 交易成本高

多空组合 = 做多第N组 + 做空第1组

```
多空组合累计收益
    │
    │                              ╱
60% │                         ╱───╱
    │                    ╱───╱
40% │               ╱───╱
    │          ╱───╱
20% │     ╱───╱
    │╱───╱
 0% │─────────────────────────────────────
    └─────────────────────────────────────→ 时间
```

**关键指标**：

| 指标 | 计算方式 | 健康值 |
|------|----------|--------|
| 年化收益 | 多空组合的年化收益率 | > 10% |
| 最大回撤 | 最大亏损幅度 | < 20% |
| 夏普比率 | 收益/波动 | > 1.0 |
| 卡尔马比率 | 收益/最大回撤 | > 1.0 |

## 6.5 因子诊断

### 6.5.1 诊断清单

| 症状 | 可能原因 | 诊断方法 | 解决方案 |
|------|----------|----------|----------|
| IC 低 | 因子逻辑问题 | 检查公式 | 优化逻辑 |
| IR 低 | 因子不稳定 | 分时段分析 | 增加平滑 |
| 分组不单调 | 非线性关系 | 分段分析 | 分段使用 |
| 换手率高 | 因子噪音大 | 增加窗口期 | 低频调仓 |
| 衰减明显 | 因子过度挖掘 | 样本外测试 | 简化因子 |

### 6.5.2 分时段诊断

将回测期分成多个阶段，分别计算 IC：

```
时段          IC均值    IR      状态
────────────────────────────────────
2021-01~06    0.052    0.65    良好
2021-07~12    0.041    0.48    一般
2022-01~06    0.038    0.42    一般
2022-07~12    0.028    0.31    较弱  ← 需要关注
2023-01~06    0.045    0.55    良好
2023-07~12    0.032    0.38    一般
────────────────────────────────────
```

**诊断结论**：
- 因子在 2022 下半年表现较弱
- 可能与当时市场环境有关
- 需要分析当时的市场特征

## 6.6 案例：诊断一个失败的因子

### 6.6.1 问题描述

创建了一个"成交量突增"因子，预期成交量突然放大的股票会上涨：

```python
class VolumeSpike(Factor):
    def calculate(self, factors):
        volume = factors['volume']
        vol_ma = volume.groupby('symbol').rolling(20).mean().droplevel(0)
        spike = volume / vol_ma
        return self.RANK(spike)
```

### 6.6.2 分析结果

```
IC 均值：     0.008   ← 接近0，几乎无效
IC 标准差：   0.145
IR：          0.055   ← 非常低
IC > 0 比例： 51.2%   ← 接近随机

分组收益：
第1组：  3.2%
第2组：  4.1%
第3组：  3.8%    ← 不单调
第4组：  2.9%
第5组：  4.5%
```

### 6.6.3 诊断分析

**问题1：IC 接近 0**

检查因子分布：
```
因子值范围：0.2 ~ 15.8
极端值比例：12.3%  ← 极端值过多
```

诊断：成交量突增因子存在大量极端值，这些极端值可能是噪音。

**问题2：分组不单调**

分行业检查：
```
行业        第1组    第5组    单调性
银行        2.1%     5.2%     是
医药        3.5%     4.8%     是
计算机      4.2%     2.1%     否（反向）
传媒        3.8%     1.5%     否（反向）
```

诊断：在科技行业，成交量放大反而是坏信号（可能是机构出货）。

### 6.6.4 改进方案

```python
class VolumeSpike_V2(Factor):
    """改进版成交量突增因子"""
    
    def calculate(self, factors):
        close = factors['close']
        volume = factors['volume']
        
        # 1. 计算成交量比率
        vol_ma = volume.groupby('symbol').rolling(20).mean().droplevel(0)
        spike = volume / vol_ma
        
        # 2. 去极值（限制在 0.5~3 倍）
        spike = spike.clip(0.5, 3.0)
        
        # 3. 结合价格信号
        returns = self.RETURNS(close)
        
        # 4. 成交量放大 + 价格上涨 = 健康的上涨
        signal = self.IF(returns > 0, spike, -spike)
        
        return self.RANK(signal)
```

改进后结果：
```
IC 均值：     0.032   ← 明显提升
IR：          0.38    ← 明显提升
分组单调性：  是
```

## 💡 本课小结

本课我们学习了：

1. **报告结构**：IC 分析、分组分析、收益归因、风险分析
2. **IC 解读**：时序图、分布图、统计指标
3. **分组解读**：收益柱状图、累计曲线、换手率
4. **因子诊断**：清单、分时段、分行业
5. **案例分析**：问题定位和改进方案

### 分析决策流程

```
运行分析 → IC 检查 → 分组检查 → 诊断问题 → 改进优化
   │          │          │          │          │
   ▼          ▼          ▼          ▼          ▼
 报告生成   IC>0.03?   单调性?    定位原因   调整参数
             │          │          │       或逻辑
             ▼          ▼          ▼
            否 →       否 →      重新设计
```
